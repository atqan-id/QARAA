# Changelog

QARAA packages are versioned independently. This file summarizes repository milestones; future package-specific release notes should be generated from Changesets.

## 0.1.0 — 2026-08-13

- Added the standalone alignment core, protocol v1 schemas and validators, unified local/remote client, in-memory Fastify server, and optional structural Sherpa-ONNX result normalizer.
- Added conformance fixtures, deterministic tracker benchmarks, TypeScript 7 consumer contracts, and dual ESM/CommonJS package artifacts.
- Added a release-safety gate that installs every package tarball into clean ESM and CommonJS projects and audits packed files, source maps, runtime dependencies, credentials, models, datasets, and application files.

No package was published as part of this milestone.
